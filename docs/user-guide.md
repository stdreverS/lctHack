# Руководство пользователя

Для п. 6.7 ТЗ. Описывает экраны платформы. Адрес — <http://localhost:8080> (Docker) или
<http://localhost:5173> (`npm run dev`), см. `docs/deployment.md`. Проекты, расчёты и каталог
хранятся на сервере; в автономном демо на моках (`VITE_USE_MOCKS=true`) — в браузере.

## Главная (`/`)

Что делает платформа, для кого, три типа объектов и путь из 8 шагов. Кнопки:
«Попробовать без регистрации», «Каталог роботов», «Войти» (или «Мои проекты», если вы вошли).

## Без регистрации

### Каталог роботов (`/catalog`)

1. Поиск по названию или производителю, фильтры «Тип объекта» и «Тип решения», сортировка
   (по названию, цене, производительности). Фильтры сохраняются в адресе страницы.
2. Отметьте «Сравнить» у двух-трёх роботов и нажмите «Сравнить» над таблицей — откроется
   сравнение характеристик; переключатель «Только различия» скрывает одинаковые строки.
3. Название робота открывает карточку (`/catalog/:id`): характеристики по группам, цены,
   источник данных, дата и статус «Подтверждено» или «Допущение».

### Оценка без регистрации (`/demo`)

Тот же мастер, что в проекте, но без сохранения на сервере: введённое хранится только в
текущей вкладке браузера (переживает обновление страницы, пропадает при закрытии вкладки).

## Регистрация и вход

- `/register`: почта, имя, пароль не короче 8 символов → «Зарегистрироваться».
- `/login`: почта и пароль → «Войти». Демо-учётка пользователя: `user@demo.ru` / `Demo12345`.
  В автономном демо на моках блок «Демо-доступ» заполняет поля одной кнопкой.
- `/app/profile`: имя, почта, роль, кнопка «Выйти».

## Проекты (`/app/projects`)

- **«Новый проект»**: название и тип объекта → «Создать проект». Параметры заполнятся
  типовыми значениями, откроется мастер.
- В таблице у проекта: **«Открыть»**, **«Копировать»** (создаёт «… (копия)» с теми же
  параметрами), **«Удалить»** (с подтверждением; удаляются и расчёты проекта).
- В проекте справа — **«История расчётов»**: дата, версии модели и данных, лучшая окупаемость.
  Запись открывает сохранённый расчёт; «Восстановить эти параметры в проект» подставляет его
  параметры и сценарии в мастер.
- «Сохранить проект» в нижней панели мастера сохраняет параметры. При уходе со страницы с
  несохранёнными изменениями платформа предупредит.

## Мастер оценки: 8 шагов

Внизу — «Назад» и «Далее»; переход дальше проверяет текущий шаг и подсказывает, что исправить.

### 1. Объект

1. Выберите тип объекта: склад, аэропорт или больница.
2. Отметьте процессы для роботизации (роботы-уборщики участвуют в подборе, только если выбрана уборка).
3. Выберите способ заполнения параметров: «Демо-данные» (типовой объект), «Заполнить вручную»
   или «Загрузить CSV».

### 2. Параметры

- Поля сгруппированы; у каждого есть единица, подсказка (ⓘ) и пример. Звёздочка — обязательное поле.
- Если значение по умолчанию взято из норматива, рядом указан источник и кнопка «Подставить».
- **Загрузка из CSV:** «Скачать шаблон CSV» → заполните столбец `value` в Excel → «Загрузить CSV».
  Платформа сообщит, сколько полей заполнено, какие ключи не распознаны и какие значения не
  прошли проверку. Разделитель — «;» или «,», дробная часть — через запятую или точку.
- «Далее» не пропустит пустые обязательные поля и значения вне диапазона: над формой появится
  список ошибок со ссылками на поля.

### 3. Подбор

Роботы разбиты на группы «Рекомендовано», «Требует проверки», «Не подходит». В карточке —
проверки (требуемое и фактическое значение, пояснение), «Нет данных: …» и «Из чего сложился
балл» — вклад пяти факторов. Отметьте «Сравнить» у одного–трёх роботов. Робота из «Не подходит»
можно добавить после предупреждения — он получит метку «Добавлен вручную». Правила подбора —
`docs/recommendation.md`.

### 4. Сравнение

Таблица характеристик выбранных роботов («Только различия» — показать отличающиеся строки).
Ниже выберите робота для сценария «Покупка» и для сценария «Роботы как услуга (RaaS)» — можно
одного и того же. Сценарий «Текущее состояние» считается всегда.

### 5. Экономика

- Ключевая цифра — лучший срок окупаемости; три колонки сценариев: капитальные затраты,
  годовой эффект, окупаемость, ROI, вывод и риски.
- «Подробно по сценариям»: вкладки со всеми показателями. Нажмите на показатель, чтобы увидеть
  формулу, исходные данные и из чего он складывается.
- **Ручная правка:** «Изменить» у числа роботов, «Изменить цену робота» → новое значение →
  «Применить и пересчитать». Показатель получит метку «изменено вручную»; «Вернуть расчётное
  значение» отменяет правку.
- **Условия аренды (RaaS):** плата за робота в месяц, срок договора, разовые затраты на внедрение.
- «Допущения и источники»: таблица допущений расчёта со статусом «Подтверждено» или «Допущение».

Формулы — `docs/economics.md`.

### 6. What-if

Панель «Допущения расчёта» (стоимость сотрудника, смены, часы, рабочие дни, загрузка, горизонт,
производительность робота, цена, обслуживание) → «Пересчитать». Таблица сравнивает сценарии с
исходным расчётом. «Чувствительность окупаемости» — график по трём параметрам для выбранного
сценария, «Показать таблицей» — те же числа таблицей. Расчёт на этом шаге ничего не меняет ни в
проекте, ни на шаге «Экономика».

### 7. Симуляция (только склад)

План склада с зонами; кнопки «Запустить» / «Пауза», «Сначала», скорость (×1…×300), перемотка,
переключатель сценария «Покупка» / «Роботы как услуга», «Сохранить изображение» (PNG кадра).
Справа — вывод «Расчёт подтверждён» или «не подтверждён», KPI, очередь заявок и загрузка
роботов. Если не подтверждён — «Пересчитать с N+1 роботом». Модель — `docs/simulation.md`.

### 8. Экспорт

- Сводка: объект, процессы, роботы, таблица сценариев, результат симуляции.
- **«Сохранить расчёт»** (в проекте) — расчёт попадает в историю.
- **«Отчёт для печати и PDF»** — полная печатная версия отчёта; на ней «Скачать PDF» открывает
  печать браузера, выберите «Сохранить как PDF».
- «Скачать Excel» — выгрузка сохранённого расчёта проекта с сервера (7 листов: сводка,
  оборудование, денежный поток, подбор, чувствительность, допущения, параметры).
- «Скачать CSV» — таблица сценариев для Excel; «Скачать схему PNG» — план объекта.

## Если что-то не работает

- Ошибки показываются текстом «что не так и как исправить», у ошибок загрузки есть «Повторить».
- «Проект не найден» — проект удалён, принадлежит другому пользователю или (в автономном демо)
  данные сброшены администратором.

## Ограничения

- «Скачать Excel» доступна для сохранённого расчёта проекта; гостю и в автономном демо на
  моках — нет. PDF — через печатную версию отчёта.
- В автономном демо на моках данные хранятся в браузере: проекты видны только в том браузере,
  где созданы.
- Симуляция доступна только для склада.
- Допущения проекта (горизонт, смены, загрузка и др.) меняются только на шаге What-if и в
  проект не сохраняются.
- Каталог роботов демонстрационный: характеристики и цены условные.
